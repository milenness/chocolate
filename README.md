# 🍫 Simply Chocolate

## 🔗 [Live Demo](https://milenness.github.io/chocolate/)

**Simply Chocolate** is an elegant and mouth-watering landing page dedicated to premium chocolate products. The project showcases a high-end brand aesthetic with a focus on visual storytelling, product variety, and an engaging user journey from the history of production to the final purchase.

## 🚀 Key Features

* **Visual Production Storytelling** — A dedicated "How it's made?" section that visually guides users through the chocolate making process with curated imagery.
* **Complex Product Grid** — A beautifully organized showcase of various chocolate types with pricing, detailed descriptions, and interactive hover effects.
* **Customer Testimonials** — A social proof section featuring reviews from "Chocolate Loved" enthusiasts.
* **Responsive Multi-device Layout** — Fully optimized for seamless viewing on mobile, tablet, and desktop screens.

## 🛠 Tech Stack

* **HTML5** & **CSS3** (SASS/SCSS)
* **JavaScript** (ES6+)
* **BEM Methodology** — Ensures a clean, modular, and professional code structure.
* **Vite** — Used as the modern build tool for high-performance development.

## 🎨 Professional Highlights

* Implemented a **visually rich interface** using high-quality imagery and custom typography to reflect a premium brand.
* Developed **interactive product cards** with engaging hover effects to improve user interaction.
* Focused on **semantic HTML** to ensure accessibility and better SEO performance.
